# Contributing to Photon

Thank you for your interest in Photon. Bug reports, testing and suggestions are always welcome as issues.

## Code contributions and the CLA

Photon is licensed under **GPL-3.0-or-later**, and the maintainer also offers it under separate commercial terms (dual licensing). To make that possible, **code contributions can be merged only if the contributor has agreed to a contributor licence agreement (CLA)** that grants the maintainer the right to relicense the contribution, or has assigned copyright for it.

>[!NOTE]
>The CLA text has not been published yet. Until it is, please open an issue to discuss a change before sending a pull request, and do not expect pull requests to be merged.

## Guidelines

* Run `cargo test --release` before submitting.
* Keep changes focused, and match the style of the surrounding code.
* Do not commit generated files (`docs/book/`) or machine-specific configuration (`.cargo/`).
